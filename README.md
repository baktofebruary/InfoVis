# InfoVis Exercise 2

## Info
- The project is split into client/server folders

## Requirements
- **Python** 3.14
- Node js
## Server
```bash
cd server
python -m venv .venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
python src/main.py
```
## Client
```bash
cd client
npm i
vite run dev # vite run build
```
